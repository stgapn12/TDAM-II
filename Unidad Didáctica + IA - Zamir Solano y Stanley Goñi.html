📚 Teoría

Conoce y comprende los conceptos fundamentales

🔵 Monomio

Es una expresión algebraica formada por un solo término. Puede ser un número, una variable o su producto.

5x²  |  -3y  |  7  |  4ab²

Partes del monomio:

CoeficienteVariableExponente

En 4x³: coeficiente=4, variable=x, grado=3.

🟦 Binomio

Expresión algebraica formada por la suma o resta de dos monomios.

3x + 5  |  2x² - 7y

Su grado es el mayor exponente de sus variables.

2 términosGrado = mayor exp.

🔷 Trinomio

Expresión algebraica formada por exactamente tres términos.

x² + 5x - 6

Trinomio cuadrado perfecto:

(a ± b)² = a² ± 2ab + b²

🌐 Polinomio

Expresión algebraica con dos o más términos. Monomios, binomios y trinomios son todos polinomios.

2x³ - 4x² + x - 8
Grado 1: LinealGrado 2: CuadráticoGrado 3: Cúbico

📋 Términos Semejantes

Tienen la misma parte literal (misma variable y exponente). Solo ellos pueden sumarse o restarse.

3x² y 5x² → semejantes ✅
3x² y 5x³ → NO semejantes ❌

📏 Grado de un Polinomio

Es el mayor exponente entre todos sus términos.

4x⁵ + 2x³ - x + 1 → Grado 5

Si hay varias variables: el grado del término es la suma de sus exponentes.

3x²y³ → grado 5 (2+3)

➕ Suma de Polinomios

📌 Reglas fundamentales

  • Solo se pueden sumar términos semejantes (misma variable y exponente).
  • Se suman únicamente los coeficientes, la parte literal no cambia.
  • Los términos que no tienen semejantes se bajan tal como están.
  • El signo de cada término va junto con su coeficiente.

✏️ Ejemplo 1 básico: (3x² + 2x - 1) + (x² - 5x + 4)

Paso 1 — Identificar semejantes: (3x² y x²), (2x y -5x), (-1 y 4)
Paso 2 — Sumar coeficientes: 3+1=4 → 4x² | 2+(-5)=-3 → -3x | -1+4=3
Resultado: 4x² - 3x + 3 ✅
Ejemplo 2 — Con una variable

(5x³ - 2x + 7) + (3x³ + x - 4)
= (5+3)x³ + (-2+1)x + (7-4)
= 8x³ - x + 3

Ejemplo 3 — Con dos variables

(4x² + 3y - 1) + (x² - 3y + 5)
= 5x² + 0y + 4
= 5x² + 4

Ejemplo 4 — Tres polinomios

(x+2) + (3x-1) + (2x+5)
= (1+3+2)x + (2-1+5)
= 6x + 6

Ejemplo 5 — Grado 3

(2x³+x²-4) + (-x³+3x²+4)
= x³ + 4x² + 0
= x³ + 4x²

➖ Resta de Polinomios

📌 Reglas fundamentales

  • Se cambia el signo de todos los términos del sustraendo (el que se resta).
  • Después del cambio de signo, se procede igual que en la suma.
  • ¡No olvides cambiar el signo de CADA término, no solo el primero!
  • Un término sin signo visible es positivo (+).

✏️ Ejemplo 1 básico: (5x² - 3x + 2) - (2x² + x - 4)

Paso 1 — Cambiar signos del sustraendo: -(2x² + x - 4) = -2x² - x + 4
Paso 2 — Reescribir: 5x² - 3x + 2 - 2x² - x + 4
Paso 3 — Combinar semejantes: (5-2)x² + (-3-1)x + (2+4)
Resultado: 3x² - 4x + 6 ✅
Ejemplo 2 — Binomios

(7x + 3) - (4x - 5)
= 7x + 3 - 4x + 5
= 3x + 8

Ejemplo 3 — Cuidado de signos

(3x² - x) - (-2x² + 4x)
= 3x² - x + 2x² - 4x
= 5x² - 5x

Ejemplo 4 — Grado 3

(4x³+2x-1) - (x³-3x+6)
= 4x³+2x-1-x³+3x-6
= 3x³ + 5x - 7

Ejemplo 5 — Con 3 términos distintos

(6x²+4x+9) - (2x²+4x+3)
= 6x²+4x+9-2x²-4x-3
= 4x² + 6

✖️ Multiplicación de Polinomios

📌 Reglas fundamentales

  • Propiedad distributiva: cada término del primer polinomio multiplica a todos los del segundo.
  • Regla de exponentes: x^m · x^n = x^(m+n) — se suman los exponentes.
  • Regla de signos: (+)(+)=+ | (−)(−)=+ | (+)(−)=− | (−)(+)=−
  • Los coeficientes se multiplican entre sí normalmente.
  • Al final se combinan los términos semejantes.

✏️ Ejemplo 1 — Monomio × Binomio: 3x · (2x + 5)

Distribuir: 3x·2x = 6x² | 3x·5 = 15x
Resultado: 6x² + 15x ✅

✏️ Ejemplo 2 — Binomio × Binomio (FOIL): (2x + 3)(x - 4)

Primeros: 2x · x = 2x²
Externos: 2x · (-4) = -8x
Internos: 3 · x = 3x
Últimos: 3 · (-4) = -12
Combinar semejantes: 2x² + (-8x+3x) - 12 = 2x² - 5x - 12 ✅
Ejemplo 3 — Monomio × Trinomio

2x · (x² - 3x + 4)
= 2x·x² + 2x·(-3x) + 2x·4
= 2x³ - 6x² + 8x

Ejemplo 4 — (a+b)(a-b)

(x+5)(x-5)
= x²-5x+5x-25
= x² - 25 (diferencia de cuadrados)

Ejemplo 5 — Trinomio × Binomio

(x²+2x-1)(x+3)
= x³+3x²+2x²+6x-x-3
= x³ + 5x² + 5x - 3

Ejemplo 6 — Cuadrado de binomio

(x+4)² = (x+4)(x+4)
= x²+4x+4x+16
= x² + 8x + 16

➗ División de Polinomios

📌 Reglas fundamentales

  • Polinomio ÷ Monomio: divide cada término del numerador entre el divisor.
  • Regla de exponentes: x^m ÷ x^n = x^(m-n) — se restan los exponentes.
  • Los coeficientes se dividen entre sí normalmente.
  • Si m=n, el resultado es x⁰ = 1.
  • Verifica: Cociente × Divisor = Dividendo.

✏️ Ejemplo 1 — Polinomio ÷ Monomio: (6x³ - 4x² + 2x) ÷ 2x

Paso 1: 6x³ ÷ 2x = 3x²
Paso 2: -4x² ÷ 2x = -2x
Paso 3: 2x ÷ 2x = 1
Resultado: 3x² - 2x + 1 ✅ | Verifica: 2x(3x²-2x+1) = 6x³-4x²+2x ✔
Ejemplo 2 — Básico

(8x⁴ + 4x²) ÷ 4x²
= 8x⁴/4x² + 4x²/4x²
= 2x² + 1

Ejemplo 3 — Coeficientes fraccionarios

(9x³ - 6x² + 3x) ÷ 3x
= 9x³/3x - 6x²/3x + 3x/3x
= 3x² - 2x + 1

Ejemplo 4 — Con dos variables

(10x²y - 5xy²) ÷ 5xy
= 10x²y/5xy - 5xy²/5xy
= 2x - y

Ejemplo 5 — Grado alto

(12x⁵ - 8x³ + 4x) ÷ 4x
= 12x⁵/4x - 8x³/4x + 4x/4x
= 3x⁴ - 2x² + 1
